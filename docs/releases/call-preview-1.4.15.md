# 닷 음성 / Voice to Dot 1.4.15-dev

한국어 앱 이름은 **닷 음성**, 영어 기본 이름은 **Voice to Dot**입니다. 기존 ChatGPT 앱의 설정된 Dot으로 이동하여 실제 음성 통화를 한 번 시도합니다. TTS/API 통화가 아닙니다.

## 이번 변경

- 이전 GPT 대화/프로젝트 화면의 실제 `상위 화면으로 이동` 버튼 구조를 인식합니다. 확인된 라벨, 비활성 장식 및 Button 역할을 함께 검증합니다.
- 닉네임 변경 후 실제로 관찰한 입력창 `리코에게 메시지 보내기`에 맞춰 해당 기기의 템플릿을 `{dot}에게 메시지 보내기`로 수정했습니다. 설정값은 APK에 개인 프로필로 포함하지 않습니다. 다른 기기에서는 실제 라벨을 확인해야 합니다.
- 30초 재실행 제한 중에는 안내를 표시하며 통화를 추가로 예약하지 않습니다.
- 한국어 표시 이름을 닷 음성으로 변경했습니다. 기존 실행 컴포넌트는 유지합니다.

## 검증

- Fold7 사용자가 이전 GPT 화면 문제 수정 후 빅스비 전체 실행 성공을 확인했습니다. 한국어 이름 적용 후 제미니 앱 열기 시험에도 정상 동작했다고 확인했습니다. 이는 사용자 보고이며 자동 녹음/음성 응답 검증은 아닙니다.
- 468개 합성 회귀 검사 및 manifest/privacy/locale/MIT 검사, 로컬 빌드와 APK v2/v3 서명 검증 통과.
- 게시 APK는 Fold7에 데이터 보존 업데이트한 동일 파일입니다. 새 서명으로 전환하지 않았습니다.

## 설치와 서명

APK, SHA256SUMS.txt, SIGNING.txt를 확인하세요. 기존 동일 서명 테스트 설치에는 Android 설치 프로그램 또는 `adb -s <확인한 기기> install -r talk-to-dot.apk`로 업데이트할 수 있습니다. 원본/CI 등 다른 서명과 충돌하면 중단하세요. 앱 제거나 데이터 삭제로 우회하지 마세요.

접근성 서비스를 사용자가 허용하고 실제 기기의 대상/버튼 라벨을 저장해야 합니다. 떠 있는 접근성 바로가기는 필요 없습니다. 잠금 해제 후 “리코 음성 대화”로 구성한 빅스비 루틴 또는 제미니에서 “닷 음성 앱 열어줘”를 사용할 수 있습니다. 프로필 별명과 앱 실행 이름은 별개입니다. 실제 통화가 시작될 수 있습니다.

## 프리릴리스 범위

버전 이름은 **1.4.15-dev**, versionCode **22**이며 기존 개발 서명을 유지합니다. 생산용 키 전환/독립 백업, 두 물리적 Fold 레이아웃, 영어 ChatGPT 화면, 모든 잠금·프로세스 재시작·권한 취소·앱 이탈 시나리오의 실기기 검증은 완료되지 않았습니다. 따라서 프리릴리스이며 전체 기기 호환성이나 정식 안정성을 보장하지 않습니다. 기존 안전 회귀 검사는 합성 환경에서 통과했습니다.

MIT 원본 고지를 유지합니다. 앱에는 녹음·네트워크 권한이 없으며 대화 내용/개인 설정/연결 정보/서명 비밀을 릴리스에 포함하지 않습니다.
